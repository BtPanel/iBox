# 功能说明

本文记录 iBox 1.0 当前源码已经实现的能力，不代表所有第三方订阅或播放服务都能正常工作。

## 点播

- TvBox 风格配置、分类、筛选、首页推荐和站点切换
- 单站搜索、聚合搜索、搜索记录和结果换源
- 详情、简介、多线路、多集、倒序选集和继续播放
- 收藏、观看历史、播放进度和媒体库
- 播放失败后的重试、同站换线路和跨站换源设置
- Java、JavaScript 与 Python 内容扩展

订阅可以被正确解析，不代表其中每个站点都提供有效播放地址。站点接口、扩展、解析接口、请求头或媒体服务失效时，应用只能报告错误或尝试已有备用线路。

## 播放器

- Media3 ExoPlayer 与 MPV 两种引擎
- HLS、DASH、RTSP、常见文件和项目扩展协议
- 字幕、音轨、弹幕、倍速、画面比例、解码与缓冲设置
- 亮度、音量、进度手势，手机画中画和后台媒体会话
- 电影级播放偏好、字幕样式、音频效果与播放计时
- 播放页弹幕搜索、设置、投屏和下载操作

如果两个引擎在同一时间点出现相同循环或跳回，通常应检查播放地址、控制器状态、解析结果和服务事件，而不是单独认定某一播放器损坏。

## 直播和 EPG

- M3U/M3U8、`#genre#` TXT 和 JSON 直播配置
- 频道分组、频道搜索、收藏、屏蔽、多线路和启动频道
- XMLTV、XMLTV gzip 和按频道请求的 JSON EPG
- EPG 缓存、刷新、日期列表、节目提醒和时间偏移
- 直播超时、重连、换线路、RTSP 传输和解码记忆
- 服务端支持时的 catch-up/时移回看、进度和 Seek

回看地址、保留天数、可定位范围和拖动精度由直播服务决定。没有回看模板或服务端不支持 Seek 时，客户端不能凭空生成回看能力。

## 手机/平板

- 触摸和手势操作，手机/平板布局切换
- 日间、夜间和跟随系统主题
- 首页推荐、历史或收藏内容选择
- 底部导航项目自定义隐藏；首次使用默认隐藏“下载”
- 启动页面支持关闭、点播、直播和历史
- 本地文件、文件夹、离线下载和离线媒体库
- 扫码、DLNA 设备发现、投屏和投屏控制
- 横竖屏、画中画和系统分享/链接打开

## Android TV

- 面向遥控器的焦点导航和横屏布局
- 点播主页、详情、搜索、收藏、历史和媒体库
- 直播分组、频道、EPG、线路与回看控制
- 主题色和独立焦点框颜色
- 启动页面选择及系统开机自动启动开关
- DLNA Renderer 接收投屏
- 推送页、二维码和局域网远程管理

## 设置与维护能力

- 点播、直播、壁纸和 EPG 订阅管理
- 播放、解码、预加载、弹幕、字幕、音频和下载设置
- 日夜主题、主题色、字号、高对比度和减少动画
- GitHub 地址自动加速及备用地址回退
- 健康检查、配置提示开关、缓存和存储隐私管理
- Room 本地数据库备份、恢复和 WebDAV 同步
- 崩溃页、Logcat 诊断和本机 HTTP 管理接口
- WebView 解析兼容旧站证书错误和 HTTP/HTTPS 混合内容
- 远程 Java 扩展兼容旧版 JAR、可选 MD5 和本地扩展格式

## 数据和隐私边界

- 应用会在本地保存订阅、收藏、历史、播放进度、直播状态和设置。
- 删除应用数据会清空数据库和偏好；离线媒体是否保留取决于文件所在目录。
- 局域网控制只应在可信网络启用，并使用项目提供的 PIN 配对和限时会话访问控制。
- WebDAV、私人订阅、请求头、Cookie 和令牌不应写入公开日志或提交到 Git。
- 内容扩展可以访问网络和应用接口，只加载可信扩展。

## 非目标

- iBox 不保证“支持网络上所有订阅源”。它支持项目实现的 TvBox 规则和输入格式，非标准字段仍需要单独适配。
- iBox 不提供或维护公共影视、直播或 EPG 内容。
- GitHub 加速只解决连接路径问题，不能修复失效仓库、错误配置和无效播放地址。
- 自动换源只能在当前配置包含可用候选源时工作。
