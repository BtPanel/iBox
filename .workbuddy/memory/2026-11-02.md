## APK 的 Python 依赖救急方案（已验证可跑通订阅）
当 chaquo 安装任务被拦、只能 `-x` 出包时，用脚本把**正确构建的旧包**里的依赖资源嫁接进新包：
1. 取 `app/build/outputs/apk/<变体>/release/iBox-1.0-<变体>.apk` 里的 `assets/chaquopy/requirements-arm64-v8a.imy`（22B 空包）和 `requirements-common.imy`（5.25MB 真依赖）；
2. 用 Python zipfile 重写 debug APK：替换这两个 .imy，并同步改写 `assets/chaquopy/build.json` 里对应 sha1；丢掉 META-INF 签名文件；
3. `zipalign -f -p 4` → `apksigner sign --ks ~/.android/debug.keystore --ks-pass pass:android --key-pass pass:android --ks-key-alias androiddebugkey`（apksigner 需要 JAVA_HOME 指向 JDK25，否则报 "Please set JAVA_HOME"）。
前提：python 源码（`chaquo/src/main/python` + requirements.txt）没变；UI 改动不影响，可放心嫁接。
验证方式：`adb -s emulator-5554 shell run-as com.media.ibox ls files/chaquopy/AssetFinder/requirements` 应能看到 requests 等目录。
根治办法：让用户在自己终端跑不带 `-x` 的 assemble（脱离沙箱不受删除保护限制），或在 WorkBuddy 设置里放宽批量删除保护。

## 壁纸背景协调（cf1575c）

用户反馈：换了壁纸后主页和分类 Tab 的背景色不协调。根因是首页顶栏用 `ibox_home_scrim`（不透明 surface_container）铺了整块，而内容区透壁纸，形成横向硬边。项目本身是"壁纸贯穿全页"的设计（BaseActivity 给每个 Activity 加 CustomWallView，设置页/收藏页/我的页根布局都是透明的），只有首页顶栏破了规矩。

修法：
- 新增 `drawable/bg_home_appbar.xml`：`gradient angle=270, centerY=0.78`，实色 → `ibox_home_scrim_clear`（同色 alpha0）。AppBarLayout 用它，品牌行与分类栏改透明。
- 新增令牌 `ibox_home_scrim_clear`：日 `#00F5F7F6` / 夜 `#000F1412`。**必须同色透明，不能用 @android:color/transparent**，否则渐变插值出灰黑边。
- `VodFragment.setBarScrim()`：折叠比例 ratio/0.45 插值给 `binding.type` 补实底，避免海报滚到 Tab 下方压字；无壁纸（`Setting.getWall()==0 && !FileUtil.getWallCache().exists()`）时回退纯色实底。
- AppBarLayout 高度 150dp（brand 56 + search 40+8 + tab 46），Tab 区落在渐变 69%~100%，文字在 84% 附近 → alpha≈73%，虚化壁纸下可读。

遗留：折叠态状态栏区仍是壁纸、下面分类栏实底，滚动时有一条轻边界（因 activity_home 用了 fitsSystemWindows，AppBar 顶不到状态栏）。要彻底消除需改成手动 window insets，风险较高未做。

### 折叠态补底改为渐变（f0ee78f）

上一版折叠时给分类栏 `setBackgroundColor` 全实色，滚动中状态栏（壁纸）与分类栏之间出现硬边。改为复用 `GradientDrawable`，按 `offset/(totalScrollRange*0.45)` 插值 `setColors({顶部 70% alpha, 底部 255})`，展开态即全透明，折叠态顶部留 30% 透光与壁纸衔接。常量 `FOLD_TOP_ALPHA = 0.70f`。

注意：`View.setAlpha()` 会影响子 View（标签文字变透明），不能用它做整体淡入，只能改背景 drawable 的颜色 alpha。

项目事实：**所有页面的状态栏区域都显示壁纸**（BaseActivity 把 CustomWallView 加到 `android.R.id.content` 第 0 层，全屏覆盖，而各 Activity 根布局的 fitsSystemWindows 只让内容避让）。所以任何页面顶部若用实色栏，折叠/滚动时都会和状态栏壁纸产生边界——首页以外的页面工具栏都是透明的，反而没这个问题。
