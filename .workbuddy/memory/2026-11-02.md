  ANDROID_HOME=C:/Users/Smile/AppData/Local/Android/Sdk
  ./gradlew -PchaquopyBuildPython="C:/Users/Smile/AppData/Local/Programs/Python/Python310/python.exe" \

  必须带 `-x` 跳过 chaquo 的 Python 依赖安装任务：该任务每次都会重装依赖并批量删除旧文件，会撞上本机环境的 `CODEBUDDY_SAFE_DELETE_BULK_GUARD`（一次删除 ≥50 个文件即拦），报 `Process ... python.exe finished with non-zero exit value 1`。依赖首次装好后，后续构建跳过该任务即可正常出包。
- chaquo 模块只有 arm64_v8a / armeabi_v7a 两个 flavor（无 leanback 变体），所以双端共用同一个安装任务名。
